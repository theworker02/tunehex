# tunehex

Tune URLs and hex query parts with stable normalization.

**Site:** https://theworker02.github.io/tunehex/

## Install / run

```bash
git clone https://github.com/theworker02/tunehex.git
cd tunehex
node src/cli.js
node --test
```
